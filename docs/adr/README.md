# Architecture Decision Records

ADRs capture durable decisions that affect multiple components or constrain future work. They explain context, alternatives, the chosen decision, consequences, and what could cause reconsideration.

## Status values

- `Proposed`: written for review; not binding.
- `Accepted`: approved and currently binding.
- `Superseded`: replaced by another ADR.
- `Rejected`: considered but not adopted.

Number ADRs sequentially as `NNNN-short-title.md`. Do not create an ADR merely to make an undecided subject look settled. Research findings belong in milestone artifacts or issue deliverables until they justify a decision.
