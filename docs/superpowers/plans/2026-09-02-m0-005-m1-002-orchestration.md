## Global Constraints

- Preserve the accepted modular monorepo and `cubeai.lab` boundary; domain code is framework-, database-, UI-, HTTP-, and provider-payload-independent.
- Preserve distinct local Cube, immutable CubeVersion, rules identity, printing identity, membership identity, and future draft-instance identity scopes.
- Treat custom or unresolved identity as explicit state; never fabricate an Oracle or printing identifier and never name-match.
- Do not add HTTP payloads, adapters, persistence, live metadata, draft instances, image downloading, browser end-to-end infrastructure, a design system, or CI.
- Use only deterministic synthetic test values; no credentials, private data, or copied provider payloads.
- Frontend quality responsibilities remain non-overlapping: Prettier formats, ESLint checks source correctness and JSX accessibility rules, `tsc` performs strict typing, Vitest performs unit tests, and Vite builds.
- Dependency changes are limited to the accepted frontend quality stack plus the direct JSX accessibility rule plugin required to make the acceptance test meaningful; keep every package locked in `frontend/package-lock.json`.
- Each task must use test-first red/green evidence, run its focused checks and its complete affected workspace suite, inspect `git diff --check`, commit only its scoped files, and report exact command output.
- No branch is merged into `main` and nothing is pushed in this plan.

- [ ] **Step 3: Implement the smallest standard-library domain model**

In `cube.py`, define a string validation helper that raises `ValueError` containing the relevant field name for blank/non-string identifiers. Define `ResolutionStatus` with exactly `RESOLVED`, `UNRESOLVED`, and `CUSTOM` values.

Define frozen dataclasses with these fields and invariants:

```python
@dataclass(frozen=True)
class SourceReference:
    source: str
    external_id: str

@dataclass(frozen=True)
class CardIdentity:
    id: str
    name: str
    resolution_status: ResolutionStatus
    oracle_id: str | None = None
    source_reference: SourceReference | None = None

@dataclass(frozen=True)
class CardPrinting:
    id: str
    card_identity: CardIdentity
    source_reference: SourceReference | None = None

@dataclass(frozen=True)
class Cube:
    id: str
    name: str
    source_reference: SourceReference | None = None

@dataclass(frozen=True)
class CubeCard:
    id: str
    resolution_status: ResolutionStatus
    printing: CardPrinting | None = None
    source_reference: SourceReference | None = None

@dataclass(frozen=True)
class CubeVersion:
    id: str
    cube: Cube
    cards: tuple[CubeCard, ...]
    source_reference: SourceReference | None = None
```

Require a nonblank `oracle_id` only for `RESOLVED` identities, and require that `UNRESOLVED` and `CUSTOM` identities have no Oracle ID. Require a printing only for a `RESOLVED` membership, and require absent printing for `UNRESOLVED` and `CUSTOM` memberships. Convert an iterable of cards to a tuple in `CubeVersion.__post_init__`; reject blank IDs and duplicate `CubeCard.id` values within one version. Do not add generic factories, JSON conversion, UUID generation, mapping behavior, transport DTOs, or metadata resolution.

Re-export the seven public types from `cubeai.lab.domain.__init__` and use `__all__` to make that limited public surface explicit.
