# CubeCobra contract excerpts

These are deliberately tiny, reviewed excerpts for the frozen M1-001 contract.
They are not complete CubeCobra responses, card lists, or adapter fixtures.

Each public-source excerpt records its exact endpoint, 2026-09-02 retrieval,
purpose, and removals. It retains only provider IDs and the structural fields
needed for an offline contract probe. Their shape was derived from observed
public CubeCobra responses and each excerpt is minimal and sanitized.
CubeCobra software licensing does not establish a license for response data;
response-data licensing is not established, and no broader reuse or licensing
conclusion is made here. The excerpts remain under the approved conservative
fixture policy. Do not refresh or expand an excerpt without documenting
upstream drift, terms/licensing context, sanitization, and intended behavior as required by
[the fixture policy](../../../docs/FIXTURE-TEST-DATA-POLICY.md).

`normal-public-mainboard.json` and `duplicate-mainboard.json` are provider
evidence. `errors.json` records real public error bodies. Custom/unresolved
behavior has no verified provider representation, so it is covered only by the
separate CubeAI-authored
[`fixtures/synthetic/duplicate-membership-unresolved-custom.json`](../../synthetic/duplicate-membership-unresolved-custom.json).
